# Quadratic Equation Solver
Solves quadratic equations in real numbers, produces a console-based animated graph, followed by a color graph showing the roots.
You can also play a graph‑creation mini‑game.

# Running Different Programs
This project includes several working modes. To launch one of them, open program folder and one of the following files:

BasicProgram.exe – the basic version of the program. It includes a parser for quadratic equations, solves them, and displays the result as an animated graph.

AiUltra.exe – the version of the program with built‑in AI.

Game.exe – the version for a single‑player game. You need to write a quadratic equation that passes through the enemies.

GameForTwo.exe – the version for two players, with the option to play against AI.
