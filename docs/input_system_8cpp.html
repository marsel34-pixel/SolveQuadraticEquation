Parses the equation string to extract coefficients a, b, and c.

Scans the entire string for numbers, and for each number calls setCoef to add its value to the appropriate coefficient based on any adjacent x-terms. The resulting coefficients satisfy a*x^2 + b*x + c = 0.

Parameters
[in]EquationStrThe equation string (e.g., "2x^2 + 3x - 5 = 0").
[out]aCoefficient for x^2.
[out]bCoefficient for x.
[out]cConstant term.
Return values
0Success.
1Error (invalid format).

Finds the power of x adjacent to a number in the equation string.

Examines the vicinity of a number (from StartN to endN) to determine if an x-term (with or without exponent) is present. If found, records its power and the coefficient value.

double * b,
double * c )

Adds the number value to the appropriate coefficient based on the adjacent x-term.

For a number located from startN to endN, this function checks for an x-term on either side. Based on the power of that term, it adds the number to:

  • a (coefficient for x^2) if power == 2,
  • b (coefficient for x) if power == 1,
  • c (constant term) if no term is found.
Parameters
[in]EquationStrThe equation string.
[in]startNStarting index of the number.
[in]endNEnding index of the number.
[in]buffCoofPointer to the numeric value to be added.
[out]aCoefficient for x^2.
[out]bCoefficient for x.
[out]cConstant term.
